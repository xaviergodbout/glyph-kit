THE SMALL PRINT, MADE SIMPLE

How it works

1

Draw

Open the SVG template in a vector editor and draw with filled shapes inside each labelled box.

2

Export

Convert strokes and text to paths, keep the guide layer and canvas intact, then export as SVG. Figma’s flattened SVG is supported.

3

Tune

Adjust every glyph’s container width with a live preview, download the TTF, then install it like any other font.
